# UI-проверки формы регистрации (Playwright / Flutter widget / вручную)

| # | Действие | Ожидание |
|---|----------|----------|
| 1 | Нажать «Зарегистрироваться» с пустой формой | Ошибки «Обязательное поле» у name, email, password; фокус на первом поле; запрос не отправлен |
| 2 | Ввести email `abc`, уйти с поля | Под полем «Некорректный email», поле помечено `aria-invalid` |
| 3 | Пароль из 7 символов | «Минимум 8 символов» |
| 4 | Ввести занятый email, отправить | Сервер вернул 409 → под полем email «Этот email занят», остальные поля сохранили значения |
| 5 | Двойной клик по кнопке | Уходит один запрос, кнопка disabled на время отправки |
| 6 | Валидные данные | Переход на следующий экран / сообщение об успехе |
| 7 | Сервер недоступен | Общее сообщение об ошибке + возможность повторить, данные формы не потеряны |
