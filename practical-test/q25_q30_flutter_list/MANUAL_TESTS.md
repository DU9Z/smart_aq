# Что проверять вручную (вопрос 30)

Автоматически (test/items_screen_test.dart): состояния загрузки / данных / пусто / ошибка+повтор,
свайп-обновление, сохранение данных при повороте, возврат из деталей, безопасный dispose.

Вручную (автотест это либо не поймает, либо дорого поддерживать):

| # | Проверка | Ожидание |
|---|----------|----------|
| 1 | Реальное устройство, режим «в самолёте» на открытии экрана | Сообщение об ошибке и «Повторить», приложение не падает |
| 2 | Медленная сеть (throttling) | Индикатор не мерцает, UI не «замирает» |
| 3 | Поворот во время загрузки | Запрос не дублируется, итоговые данные отображаются |
| 4 | Поворот на детальном экране и возврат | Позиция прокрутки списка сохранена |
| 5 | Системная кнопка «Назад» / жест «назад» | Возврат на список, без перезагрузки |
| 6 | Крупный шрифт, тёмная тема, TalkBack/VoiceOver | Тексты не обрезаются, элементы озвучиваются |
| 7 | Визуальное качество: отступы, анимация свайпа | Соответствует макету |
